Claims is where you submit reimbursements and IT declarations.

## Reimbursements

1. Go to **Claims**.
2. Choose **New claim**.
3. Enter the category, amount, receipt note, and the pay month the claim should land on. The default is last month, the same period Pay run opens on.
4. Submit. A payroll manager approves or rejects it.

Approved claims appear as `Core:` earnings when that pay month is calculated.

## IT declarations

Use the **IT declarations** tab for 80C, HRA, and other exemptions for the financial year. Choose Old or New regime. Approved totals reduce TDS on later pay runs when store TDS is on.

Managers see the store queue. Everyone else sees only their own submissions.
