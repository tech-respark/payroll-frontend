The staff directory is the same Staff screen employees use for their profile, with a list on the left when you can see other people.

If you can only see yourself, the sidebar calls this **Profile** and pins it at the bottom. There is no directory column.

You need view-other-staff or manage-staff permission for the directory. Manage permission enables create and edit.

## Add a person

1. Open **Staff**.
2. Start a new record.
3. Complete Personal & Access, Joining & Employment, Banking & Documents, and Work Experience as needed.
4. Save.
5. Assign a store role so the person receives the right screens at the next sign-in. Role assignment is done from [Roles and permissions](/docs/roles).

A valid role at the store is required for expected access. Saving the profile without a role leaves the person unable to see most of the app.

## Keep records current

- Use the shared staff picker when you set a reporting manager.
- Confirm before removing a document or experience row.
- Hospitality stores should keep pay cycle, employment type, job codes, overtime multiplier, ESI number, and PAN up to date.
- **Standard working hours / day** is hours in a normal working day (not a weekly total). It feeds overtime and daily-rate pay.

## Identifiers

Staff ID is the internal record. Employee code is the HR or device identifier. They are not interchangeable. Biometric imports depend on a stable employee code.

## External import

Some organizations import people from another system. Imported roles start with no permissions and need review. New imported users cannot sign in until a password is set or they complete forgot-password.
