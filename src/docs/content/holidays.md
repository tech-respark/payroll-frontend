The holiday calendar publishes store holidays that attendance and optional-holiday leave can use. You need leave management permission to add or delete holidays. Everyone can still read store dates when they apply for a leave type that allows an optional holiday.

## Browse the month

The page is a Monday-first month calendar plus a list of holidays. Metrics sit above the grid. Today is marked. Each holiday appears as a pill on its date.

## Add a holiday

1. Open **Holiday Calendar**.
2. Choose **Add holiday**, or click a day to open the drawer with that date filled.
3. Enter the name and details.
4. Save.

## Remove a holiday

Delete from the list view, or open the drawer on a day that already has holidays.

Attendance uses these dates when it marks a public holiday. Leave uses them when a type allows an optional holiday to be attached to a request.

> **Note:** A holiday is store-scoped. Publishing it here does not file a government calendar or change another store.
