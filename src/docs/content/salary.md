Salary Management holds the pay structure used to calculate a month. You can open it with salary view or manage permission. Saving changes requires manage permission.

If you can only see yourself, the directory column is hidden. Managers who can pick among several people keep the list beside the editor.

## Fixed salary

**Configure Fixed Salary** is the standing structure — the earnings and deductions that repeat every month. Definitions can be fixed amounts or formulas. Evaluation order follows the component priority.

## Monthly variables

**Monthly Variables** are additions or deductions for one month only. Month and year sit on the card header. Load the period, edit the values, and save.

Fixed save does not wipe monthly-calculated rows.

## Before you run a month

1. The staff record and store assignment are correct.
2. Fixed components exist for the person.
3. Daily attendance is complete and regularizations are decided.
4. The monthly attendance summary has been calculated.
5. Formula names used in rules still match the components.
6. The period is not blocked by the store payroll lock.

## Formulas

Some components calculate from attendance totals such as absent days, penalty days, late minutes, overtime, and extra days. Only trusted administrators should edit formulas.

When the month is ready, open [Payslips](/docs/payslips) to review, print, or download. Hospitality extras are applied on top of this engine — see [Hospitality payroll](/docs/hospitality).
